\subsection*{Exercise 6}
(a)
$$x \in \bigcup \mathcal{P} A \Rightarrow x \in X \in \mathcal{P} A$$
By definition of power set, this means that $X$ is a subset of $A$. Hence,
$$x \in X \subseteq A$$
$$\Rightarrow x \in A$$
For the other direction, if $x \in A$, then the singleton $\{ x \}$ is a subset of $A$. In other words, $\{ x \} \in \mathcal{P} A$. Since $x \in \{ x \} \in \mathcal{P} A$, then $x \in \bigcup \mathcal{P} A$.

\noindent
(b)
$$X \in A \Rightarrow X \subseteq \bigcup A \Rightarrow X \in \mathcal{P} \bigcup A$$
Equality only holds when $A$ is a power set (of some arbitrary set).

\subsection*{Exercise 7}
(a)
$$X \in \mathcal{P} A \cap \mathcal{P} B$$
$$\Leftrightarrow X \in \mathcal{P} A \text{ and } X \in \mathcal{P} B$$
$$\Leftrightarrow X \subseteq A \text{ and } X \subseteq B$$
$$\Leftrightarrow X \subseteq A \cap B$$
$$\Leftrightarrow X \in \mathcal{P} (A \cap B)$$

\noindent
(b)
$$X \in \mathcal{P} A \cup \mathcal{P} B$$
$$\Rightarrow X \in \mathcal{P} A \text{ or } X \in \mathcal{P} B$$
$$\Rightarrow X \subseteq A \text{ or } X \subseteq B$$
$$\Rightarrow X \subseteq A \cup B$$
$$\Rightarrow X \in \mathcal{P} (A \cup B)$$
The crucial step is when: $X \subseteq A \text{ or } X \subseteq B$ implies $X \subseteq A \cup B$. The reverse is not necessarily true. In fact, to make it true, either $A \subseteq B$ or $B \subseteq A$.

\subsection*{Exercise 10}
We know from a previous exercise that $B \subseteq \mathcal{P} \bigcup B$. So, if $a \in B$, then $a \in \mathcal{P} \bigcup B$, hence $a \subseteq \bigcup B$. Now, clearly, every subset of $a$ will be a subset of $\bigcup B$ by transitivity. Formally, $x \subseteq a \Rightarrow x \subseteq \bigcup B$. This is equivalent to $\mathcal{P} a \subseteq \mathcal{P} \bigcup B$. Hence, $\mathcal{P} a \in \mathcal{P} \mathcal{P} \bigcup B$.

\subsection*{Exercise 11}
First equation:
$$A = A \cap (B \cup B^c) = (A \cap B) \cup (A \cap B^c) = (A \cap B) \cup (A - B)$$
Second equation:
$$A \cup (B - A) = A \cup (B \cap A^c) = (A \cup B) \cap (A \cup A^c) = A \cup B$$
Note that the complement is not a set. Although it can be avoided, it's just easier to write down and conveys the same idea.
