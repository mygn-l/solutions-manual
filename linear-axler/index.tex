\section{Dimension}

\subsection*{Exercise 2.C.1}
If $U$ is a subspace of $V$, then there exists $W$ such that $U \oplus W = V$. So we have
$$\dim U + \dim W - \dim (U \cap W) = \dim V$$
Since $U \cap W = \{ 0 \}$, then $\dim (U \cap W) = 0$. With the fact that $dim U = \dim V$, we cancel both sides and are left with
$$\dim W = 0$$
So $W = \{ 0 \}$. Hence,
$$U \oplus \{ 0 \} = V$$
which implies $U = V$.

\subsection*{Exercise 2.C.2}
Every subspace must contain the additive identity $0 = (0, 0)$. Hence, the latter forms the trivial subspace $\{ 0 \}$.

If we include an additional vector in a subspace $U$, i.e. $\{ 0, v \} \subseteq U$, then $av \in U$ as well, for every $a \in \mathbb{R}$. These represent lines in $\mathbb{R}^2$.

If we include two vectors, i.e. $\{ 0, v, w \} \subseteq U$, then either $w \in span\{ v \}$ or not. In the former case, we have $w = av$ so we are still left with a line. In the latter case, $v, w$ are linearly independent, so $U$ has dimension 2. Using the result from the previous exercise, it follows that $U = \mathbb{R}^2$.

\subsection*{Exercise 3.A.3}
These form a basis for $F^n$, called the trivial basis:
$$e_1 = (1, 0, 0, \ldots, 0)$$
$$e_2 = (0, 1, 0, \ldots, 0)$$
$$\vdots$$
$$e_{n - 1} = (0, 0, \ldots, 1, 0)$$
$$e_n = \underbrace{(0, 0, \ldots, 0, 1)}_{n \text{ components}}$$
When applying $T$ on a vector $x$, we represent it using the trivial basis $e_i$, and we employ linearity as follows:
$$T(x) = T(x_1, x_2, \ldots, x_n)$$
$$= T(x_1 e_1 + x_2 e_2 + \cdots + x_n e_n)$$
$$= x_1 T(e_1) + x_2 T(e_2) + \cdots + x_n T(e_n)$$
Notice that $T(e_i)$ obviously do not depend on the input $x$. So they are constants inherent to the linear map. They are also vectors which \textit{exist} in $F^m$. We can enumerate their components:
$$T(e_1) = (A_{11}, A_{21}, \ldots, A_{m1})$$
$$T(e_2) = (A_{12}, A_{22}, \ldots, A_{m2})$$
$$\vdots$$
$$T(e_n) = (A_{1n}, A_{2n}, \ldots, A_{mn})$$
We can use this representation, plugging it back into the previous set of equation
$$T(x) = x_1 (A_{11}, A_{21}, \ldots, A_{m1}) + \cdots + x_n (A_{1n}, A_{2n}, \ldots, A_{mn})$$
$$= (A_{11} x_1 + A_{12} x_2 + \cdots + A_{1n} x_n, \quad \ldots \quad, A_{m1} x_1 + A_{m2} x_2 + \cdots + A_{mn} x_n)$$
To reiterate, every vector $x$ follows this transformation, because they can all be represented in the trivial basis, the latter which transform identically each time.

\subsection*{Exercise 3.A.12}
Let $V$ have dimension $n$, and consider a basis $e_1, e_2, \ldots, e_n$. Consider the set of linear functions that map this basis to a portion of the basis $f_1, f_2, f_3, \ldots$ of $W$:
$$T_1 (e_i) = f_i$$
$$T_2 (e_i) = f_{n + i}$$
$$T_3 (e_i) = f_{2n + i}$$
$$\vdots$$
These are well-defined functions. (In effect, the basis transformation uniquely determine every other vectors' transformation.)

Since each $T_k$ affects a set of components in $W$ that do not overlap with each other, then if we want the linear combination of these functions to produce the zero function, i.e.
$$\sum_{k = 0}^\infty a_k T_k (v) = 0 \quad \text{ for all } v \in V$$
then each $a_k$ must be zero. Hence, these functions are linearly independent. This list of linearly independent functions can be extended to a basis of $W$. Since the list of functions is infinite, then the basis, which is its superset, must be infinite as well. Hence, $\mathcal{L}(V, W)$ is infinite-dimensional.

\section{Matrices}

\subsection*{Exercise 3.C.1}
Given a map $T$, we can use its matrix representation:
$$T(v_1) = A_{11} w_1 + \cdots + A_{n1} w_n$$
$$\vdots$$
$$T(v_m) = A_{1m} w_1 + \cdots + A_{nm} w_n$$
where $w_1, \ldots, w_n$ is a basis of $\text{range } T$. We argue that for each $w_i$, one of $A_{ik}$ for some $k$ must be nonzero.

Otherwise, suppose for contradiction that none of the basis vectors $v_j$ produce a nonzero multiple of $w_i$. Then, none of the linear combinations of $v_j$ produce a nonzero multiple of $w_i$. Which means $w_i$ is not in the range of $T$, which would contradict the assumption that $w_i$ is a basis vector of $T$.

Since we now know that there exist nonzero $A_{ik}$ for each basis $w_i$, then the number of nonzero entries for the matrix $A$ is at least $n = \dim \text{range } T$.

\subsection*{Exercise 3.C.3}
For every linear map, given a basis $e_1, \ldots, e_n$ of $V$, we compute their image:
$$T(e_j) = f_j$$
We know that $f_1, \ldots, f_n$ spans $\text{range } T$. We can reduce it to a basis by removing vectors. Using a similar approach to the textbook, when we find a vector contained in the span of the remaining vectors, we remove that vector. However, most likely, we will be removing a vector somewhere in the middle of $f_1, \ldots, f_n$.

Let's say this happens at index $k$. When this happens, we relocate $k$ to the end, and shift everything else. In other words, $e_i$ and $f_i$ remain unchanged for $i < k$, but $e_i, f_i \rightarrow e_{i - 1}, f_{i - 1}$ for $i > k$, and $e_k, f_k \rightarrow e_n, f_n$. All of this is possible simply because a basis is unordered.

Since we are working in finite-dimensional space, this procedure will eventually end. When it ends, we get a basis $f_1, \ldots, f_m$. Looking back at our linear map, we notice that
$$T(e_j) = A_{jj} f_j$$
where re-ordering has been done, such that $A_{jj} = 1$ only for $j \leq m$, where $m = \dim \text{range } T$.

\subsection*{Exercise 3.C.6}
If every entry of $\mathcal{M}(T)$ is 1, then for any choice of basis for $W$, we have
$$T(e_k) = f_1 + \cdots + f_n$$
for every $k$, where $n = \dim W$. Since every basis $e_k$ is mapped to this sum, then every linear combination of them is mapped to this sum. Hence, this sum is a basis for $\text{range } T$, so its dimension is 1.

To prove the other direction, since $\dim \text{range } T = 1$, then it has a basis $f$ such that $T(e_k) = a_kf$ for some $a_k \in \mathbb{F}$. In other words, all basis vectors of $V$ are mapped to a multiple of $f$. We can even do better: simply use $e_k' = \frac{1}{a_k} e_k$, which produces $T(e_k') = T(\frac{1}{a_k} e_k) = f$. In other words, we can find a basis of $V$ that are all mapped to $f$ under $T$. We use these $e_k'$ as our desired basis for $V$.

Now, we want to express $f$ in a basis of $W$ where each coefficient is 1:
$$f = f_1 + \cdots + f_n$$
Clearly, it's possible. Simply fix every $f_1, \ldots, f_{n - 1}$. Then solve for $f_n$:
$$f_n = f - (f_1 + \cdots + f_{n - 1})$$
Hence, substituting into the first equation, we get
$$T\left( e_k' \right) = f = f_1 + \cdots + f_n$$
As you see, the entries of $A$ are 1.
